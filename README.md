#WorkEdu_Web_Project

Projet de Développement Web - L3 Informatique
Ce projet, réalisé durant le semestre 6 de la Licence 3 Informatique, consiste à développer un site web éducatif structuré selon l'architecture MVC (Modèle-Vue-Contrôleur). Le site propose deux interfaces principales : une pour les utilisateurs et une pour les administrateurs.

#Fonctionnalités

Côté Utilisateur
Accès aux cours : Consultation et suivi des cours publiés.
Participation active : Inscription et participation aux cours.
Achèvement des cours : Suivi des cours jusqu’à leur complétion.
Quizz : Évaluation des connaissances grâce à des quizz intégrés.
Forum de discussion : Échange d’idées et discussions sur les sujets des cours.
Côté Administrateur
Gestion des membres : Ajout, modification et suppression des utilisateurs.
Supervision du forum : Modération des discussions pour garantir un environnement sain.


#Base de Données

La base de données est au cœur du système, permettant une gestion fluide des informations essentielles :
Utilisateurs : Profils, inscriptions, progression et scores.
Cours : Contenu, progression et structure des cours.
Quizz : Questions, réponses et résultats des utilisateurs.
Forum : Sujets, messages et historique des discussions.
Administrateurs : Informations et permissions spécifiques.
Une attention particulière a été portée à la conception de la base pour garantir des performances optimales et une expérience utilisateur fluide.


#Technologies Utilisées

Langages : PHP (82.7%), CSS (15.6%), JavaScript (1.7%)
Architecture : MVC (Modèle-Vue-Contrôleur)

#À propos

Développement d'un site web éducatif avec une architecture MVC. Le site est structuré en deux parties principales :
Une interface utilisateur pour les apprenants.
Une interface administrateur pour la gestion.
